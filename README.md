Hello everyone, this is an English-Russian dictionary that you can fill out yourself. When you enter the dictionary, it will ask you to enter a single word in English that you have added to the dictionary. If you enter the correct translation of the word, it will remain in the dictionary. However, if you enter an incorrect translation, the word will be removed from the dictionary and you will need to add it again. You can also check your knowledge at any time by clicking on the "Check" button, which will display a window asking you to translate a random word from your dictionary into Russian.
